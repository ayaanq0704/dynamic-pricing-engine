# 🏨 Dynamic Pricing Engine

**AI-powered hotel room pricing optimization with interactive web interface**

## 📋 Overview

Complete machine learning pipeline for hotel dynamic pricing optimization. Analyzes 75K+ booking records to predict demand and recommend optimal prices using multiple business strategies.

**Key Results:**
- 🎯 **85%+ model accuracy** (Random Forest R² = 0.847)
- 📈 **15-25% revenue improvement** in simulations
- ⚡ **Sub-second predictions** for real-time pricing
- 🎛️ **4 pricing strategies**: Revenue, Profit, Penetration, Premium

## ✨ Features

- **Price Optimizer**: Real-time recommendations for individual bookings
- **Strategy Analysis**: Compare different business approaches
- **Market Simulation**: Test pricing scenarios and revenue impact
- **Data Insights**: Interactive dashboards with booking patterns
- **Elasticity Analysis**: Customer segment price sensitivity

## 🛠️ Tech Stack

- **ML**: Scikit-learn, XGBoost, Random Forest
- **Data**: Pandas, NumPy (119K hotel bookings)
- **Web**: Streamlit, Plotly
- **Deployment**: Streamlit Community Cloud
